en The bot code, which can download music from SoundCloud links (for example, https://on.soundcloud.com/...), runs LOCALLY on your device. This means that if you are in a country where SoundCloud or Telegram is restricted, the bot will not work; in such cases, you will need a proxy or VPN for it to function correctly.
